## 已交付

- 业务页以 Agent Chat 为主，手动查询和 Library 操作折叠；Admin 按
  SIS、Moodle、Portal、Library 分组，各模块只显示自己的参数。
  主要导航、诊断和任务提示使用中文，技术接口与原有确认按钮保留英文。
- 连接请求有超时反馈；重复点击不会重复启动；Host 断线取消旧请求，
  重连重新读取。Core 已连接但 Bridge 断线时每 15 秒刷新本地状态，
  不自动登录、MFA、改变开关或执行预约。
- 任务状态中心只读展示 F3 规则、最近最多 50 次运行和有限 F4 授权，
  显示精确目标摘要、阶段、错误、时间和尝试/成功/写入次数。
  F3 偏好只展示首选摘要，不能替代实际候选。UTC 明确转换为 HKT；
  不带时区的异常时间不按 Windows 时区猜测。
- 任务刷新默认手动，可选每 15 秒刷新；离开页面停止。刷新失败标记
  旧快照；某个列表失败不是“零任务”；提交未知明确要求人工核对，禁止重试。
- Admin 一键本地检查：Core、Bridge、扩展版本、本地目录、F2 开关、
  F3 调度器与 F4 运行时。不会访问现场 HKU 页面；真实写入开关打开时
  标记 needs_review，不擅自关闭，也不因为“接口可用”宣布预约安全。
- Admin 脱敏验收报告：版本/检查状态、最近 100 条本地 Admin 调用摘要、
  人工 pass/fail/pending/needs_review 计数、错误与关联 ID。
  不含预约目标、输入、课程行、DOM、账号、凭据或 arming digest。
  在只读文本框复制保存；生成报告不会修改历史或人工验收标记。
  历史不可读时明确报告错误，不用空历史冒充已通过。
- 23 个 Agent Chat 工具保持只读；没有增加模型可调用写操作。

## 醒来后一次集中验收

1. 保存会话，完全退出 Desktop，再确认安装 0.19.1。本批没有新增 Core
   代码，不需要为了 UI 更新重启 Core。重新加载 Chrome 扩展 0.17.24，
   刷新已打开的 HKU 标签页；如需登录/MFA，手动完成。
2. 打开 HKU AGENTS：检查 Agent Chat 引导和折叠手动区域。点击
   Start and connect / Connect HKU 一次，确认连接信息和扩展版本。
   若 Bridge 尚未连接，观察提示而不是连续点击；不要为测试断线中断正在提交的预约。
3. HKU Admin 点击“一键本地检查”。Core、目录和状态接口应有结果；
   Bridge/版本未知须显示 needs_review，不得误报 pass。
   默认 F2=false，F4 execution_enabled=false / dry_run=true；检查不会改变它们。
4. 展开 SIS、Moodle、Portal、Library，确认参数和按钮各归其位。
   在 Chat 做一次 Moodle 截止日期查询和一次 Library 日期查询即可作为
   旧接口冒烟测试；需要重新验收的 F1–F4 按上一批文档集中完成，
   优先 F3 shadow + F4 dry run，不必为本批做真实预约。
5. 任务状态中心点击“刷新任务状态”，与 F3/F4 原始结果对照阶段和目标。
   开启可选刷新，确认时间更新；关闭或离开页面后应停止。
   不完整快照和 unknown 不能当作已预约/未预约证据。
6. 在测试历史标记实际验收结果，再点击“生成脱敏验收报告”。检查
   人工计数和历史摘要，复制文本保存。不要将 pending 改成 pass 来隐藏问题。

本批没有清理规则、删除历史、提交预约、改变现有任务、修改预约开关，
没有 commit；0.19.1 已在用户明确确认后安装。真实预约、午夜开放行为和新 UI 目视
验收仍由用户确认；Gradio 恢复入口保留。
